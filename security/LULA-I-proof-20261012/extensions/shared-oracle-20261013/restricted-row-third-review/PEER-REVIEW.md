**PROVED.** Fix P and the selected valid address before the child, then condition on other-domain values that compute C. For that fixed C, its complete two-block base/counter row and the distinct-base region are disjoint coordinates of the same product function. Further conditioning on the entire same-C row, including rejected counters, selected full256 Y, unused counters and bottom, leaves the off-base function product-uniform. A target chosen by the first accepted counter can have a biased prefix, but every particular selected prefix y has collision probability 1/N against an independent off-base prefix. The argument requires no conditioning on a quantum transcript or on absence of an adversarial hit.

**PROVED.** Preparing C and the canonical row before A's pre-key Raw phase is lawful because this computation and A's phase act on disjoint private registers, controlled by the same read-only static oracle table. They commute in each oracle block and therefore in their joint cq state, including correlations with the oracle and an arbitrary reference. Withholding P/pk from A remains the source chronology even though the reduction knows P. This reasoning fails if C or the selected address is chosen from A's output, or if the pre-target interface admits Raw access that cannot be postponed. Neither is assumed here.

## 2. Full reply and quantum completion

**PROVED.** A Bernoulli(1/N) mark, an independent uniform hit completion, and an independent uniform non-target-prefix miss completion produce exactly uniform full256 words. Prefix and lower limbs are kept together. The oracle applies the same word to repeated queries; it is not independently resampled per call. The two-query compute/reply/uncompute circuit returns its mark scratch to zero. Outside words may use a fixed Boolean query index and ignore the computed mark until unquerying; no controlled oracle or measurement of coherent support is required. Equality on every basis input establishes equality on arbitrary superpositions and entangled inputs.

**CITED.** The cached primary paper SPHINCS+C (https://eprint.iacr.org/2022/778), Appendix E, printed page35, Theorem E.3 gives `8*lambda*(k+1)^2`; Lemma E.4 explicitly instantiates a two-query Boolean simulation. The PDF SHA is 1d24bcee44b6a719004cf6da5fd22275a06e2dac8a3a72acd8f8caa823a29215 and cached text SHA is 833bcca0db93c57c3eff21e7982eb122aa386cdb2cdcdb696721d086cd406078. Metadata was checked through the official ePrint page; the actual constant was read in the local primary text. Accordingly two Boolean calls per M fullRaw calls gives `U2(M)=min(1,8*(2M+1)^2/N)`. This is a sufficient substitution, not a proof that no one-query completion exists. The author's phrase "It is NOT8(M+1)^2/N" must be read as referring to this two-query substitution only, not a lower bound against other circuits.

**PROVED.** Dummy f coordinates for V=C complete the full160-bit Boolean domain but do not appear in eligible output words. This avoids an unproved non-power-of-two-domain variant. Fixed independent auxiliary tables can be supplied to the Boolean search algorithm; they do not leak marks. The construction may have enormous gate/storage costs. Query complexity and efficient local coherent realization remain distinct.

## 3. Which source calls count

**PROVED (literal input reading).** A selected addressed type7 word has length106 and starts `P16||zero48||A22`. H_msg inner has form `R16||P16||root16||message`: equality forces P=0 at bytes16..31. H_msg outer has length52 and cannot equal the selected106-byte word. Types 0--4 have different literal address type fields. Honest type7 calls at the selected address always use the genuine C, including rejected searches and digest rechecks; other addresses are outside. All these structural exclusions are at P!=0 and honest/genuine-cache scope only. No query-support test or adaptive no-hit conditioning is used.

**PROVED.** Every adversarial fullRaw call is charged, including pre-key work and classical calls. The preserved target adapter executes the final selected digest and thus has `M<=Q+1`, giving `U2(Q+1)=min(1,8*(2Q+3)^2/N)`. The new search extractor reaches the selected final verifier call, computes its eligible classical (V,c), and stops before evaluating that digest. On every selected source `Win AND D7_base_final` branch it therefore outputs a marked candidate. Other branches can only enlarge its search success; no full source Win test is needed. This distinct program has `M<=Q`, giving `U2(Q)`. It must not be described as the old completed-verification adapter.

**PROVED.** Target canonical preprocessing, source setup/signing and all other final verifier calls still count toward total time, memory and global honest oracle resources, even when outside the changed region. Omitting them from M is justified by their independence from f, not by declaring them costless. Bounds that count only coherent A queries while permitting uncharged classical A Raw queries are invalid. P=0 is handled externally exactly once, or the complete resource cap must replace the structural cap there.

## 4. Exhaustion and selection

**PROVED.** With acceptance fraction p, target mass is `tau=1-(1-p)^(2^32)` and bottom branches retain their probability mass. A stronger primitive bound is `tau*U2(M)`; dropping tau is conservative. There is no reciprocal tau, no forced target success and no resampled accepted image. For the specified source partial game, a bottom selected target has zero honestly exposed successful selected-row event. This is not a new global source abort, nor a claim that native Rust aborts on overflow: the bounded-counter partial abstraction is already explicit in the accepted parent reduction.

**PROVED (composition).** Separate low/top selectors give losses2^42 and2^21. Their eligible events can be bounded by the same Q cap without claiming security level, signing limit, or equality of optimal advantages. The resulting source component inequality is a sum of sufficient selected-event upper bounds; other signature terms and the seed-zero event remain separate.
