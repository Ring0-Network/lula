## Independent checks of the accepted wrapper

**Child-before-parameter release.** HK Definition7 grants classical Col at the challenger's hidden P. Source `child_value` uses types0..4 with the same parameter, never type7. The target tweak contains type7, so challenge/collection tweak sets are disjoint even across payload lengths. The bottom FORS child is obtained from its actual forest and the persistent F values; upper children are actual lower height5 subtrees. Knowledge of P is unnecessary for phase1's computation. Arbitrary keyed collections need not exhibit row independence, and the wrapper does not assume it.

**Source pre-key alignment.** For public fixed h, B may finish primitive registration and receive P before running A's pre-key phase, while withholding P/pk from A. The private schedule changes only hidden computations of a fixed function. The chosen child is key-only and independent of A's message choices. A's pre-key and later raw computations use the same h throughout. For an external O, an analogous statement is conditional on the explicitly shared global O and its exact fullRaw interface. No reset of its values or erasure of A's prequeries is allowed. The peer explicitly distinguishes these cases; it does not derive external-O access from public algorithm access.

**Canonical law.** The named oracle searches the literal20-byte payloads `C16||BE32(c)` in order for c<2^32. Once c0/y are returned, selected source searches/rechecks reuse them. FullY follows from computing h at the now known exact word. Rejected counter outputs remain evaluations of h; no accepted-output resampling occurs. A selected bottom branch contributes zero to the selected exposed-successful-row event, even if that source row would otherwise remain unrequested. Failing B at bottom therefore does not add a global source setup failure or condition source keys on success.

**Exact law and stopping.** The unflagged comparator can continue with source law when target exists. Actual B may stop upon a valid collision before full root acceptance. This can only increase primitive success. On bottom, use event-specific zero contribution, not an assertion that B still produces the full source transcript. These are the same stopping/partiality qualifications as in the existing type7 program.

**Low/top split.** Prop4 is32 width4 digits summing240; Prop8 is16 width8 digits summing2040; z=0 in both. Neither is a substitute for the other. The exact row counts are2,269,957,324,800 low rows and2,097,152 top rows. A42-bit low pad gives2^-42 to each genuine low row and unused indices fail; a21-bit top selector gives2^-21 to each top row. Splitting the first eligible final event yields the peer inequality. No target-success normalization and no inverse-acceptance-probability factor is present.

**Collision eligibility.** V!=C is essential. It proves distinct raw words despite allowing every BE32 candidate counter, including c0. Same-child counter-only equality is not a C.1 changed-message collision. Equality of source digit vectors means equality of all128 prefix bits by injective full128 decoding. The wrapper correctly outputs a128-prefix collision, not necessarily a full256 collision.

**Complete resources.** The single pre-key target has up to2^32 oracle evaluations internally. Child preparation uses17,392 Col calls/8,704 F labels at layer0 or15,423 Col calls/1,024 F labels above. The top row's child is still height5. Phase2 includes actual huge setup/signing work and all source raw computations, final verification, message bytes, persistent F/J tables and malicious raw computation work. An external quantum-RO formulation must add those honest classical O calls to the primitive reduction's relevant oracle budget; passing A's own Q_q alone to a theorem would omit them. Public implementation h instead incurs explicit algorithm time/gates. None of this is waived by the collection oracle or by the selector.

**Countermodels.** The peer's standalone-vs-collection keyed leakage example correctly separates security properties; collection access can correlate C with the hidden key and therefore needs its own assumption. Its success1/success0 counterpolicy model correctly refutes uniform policy interchangeability. Neither is a source attack, nor a refutation of the chosen canonical collection instance. The ordinary trunc128 collision fallback is a valid distinct assumption-parametric route; it does not imply a64-bit signature forgery or satisfy the original128-bit requirement quantitatively.
