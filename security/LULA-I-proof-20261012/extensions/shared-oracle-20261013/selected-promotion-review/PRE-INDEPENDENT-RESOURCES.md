## Prefix-only challenger and lower limbs

A challenge supplying only f(X), where X is uniform128-bit and f is the selected random-oracle prefix, can support an event-specific extension to full256 raw answers on surviving prefixes. On a selected16-byte query with prefix equal to the target, output that input and stop successfully before returning any full response. The genuine X necessarily takes this stopping branch. A lower limb correlated with the unknown X need never be emitted. Alternate prefix preimages only provide additional valid challenge wins; they cannot invalidate the lower bound on captured genuine first hits.

This statement requires explicit stopping before the response. It does not give a full ordinary challenger-controlled full256 function after the stop, does not permit resampling a lower limb that was already emitted, and does not justify an externally supplied opaque Raw_out being reprogrammed.
