# GOAL — complete security proof of LULA I (closes the four open points)

Role: cryptographic proof author and checker. Not a paper editor. Output is a proof document (LaTeX or Markdown with formulas), a numeric script, and a verdict per term. Do not edit LULA-I.tex. Do not assert any bound you have not derived or computed. Every statement carries one label: PROVED, COMPUTED, CITED(source), ASSUMED. If a step cannot be closed, say "OPEN" and give the smallest missing lemma.

## 0. Fixed object (from the paper and the R6A record; verify each against the code)
n = 16 B hash output (SHA-256 truncated). Signature 5,720 B = 16 (randomizer) + 4 (counter) + 2,720 (FORS+C) + 5·596 (five WOTS+C layers with authentication paths). Public key 32 B. Seed 48 B.
FORS+C: k = 18 trees, the last forced to leaf index 0 by grinding, so k' = 17 trees are real; a = 9 (2^9 leaves per tree).
Hypertree: d = 5 layers, total height h = 41. Layers 0–3: h' = 5, w = 16, ℓ = 32 chains, target sum S = 240. Layer 4: h' = 21, w = 256, ℓ = 16, S = 2040.
Signer is deterministic. The optional cache (top tree, 2^22−1 nodes of 16 B and 2^21 counters of 4 B) stores recomputable values only.
Design scenario: q ≤ 2^38 or 2^40 signatures per key (the author chooses; compute both and 2^41).
Target: EUF-CMA at classical level 1 (≥ 128 bits), then the quantum reading (NIST category 1, about 2^64 quantum queries).

## 1. Point 1 — the forgery game of the complete signer
Define the experiment Exp^{euf-cma}_{LULA}(A) formally.
1. Key generation: sk = (sk_seed, sk_prf, pk_seed) ∈ {0,1}^{384}; pk = (pk_seed, root), root = top node of the hypertree.
2. Signing oracle O(m): returns σ = (R, ctr, σ_FORS, (σ_WOTS^i, auth^i)_{i=0..4}), computed by the deterministic reference algorithm. Number of queries ≤ q.
3. A wins iff Verify(pk, m*, σ*) = 1 ∧ m* ∉ {m_1,…,m_q}.
Write the signer as an explicit sequence of oracle calls: H_msg, PRF, PRF_msg, F, H, T_ℓ, chain function, address schema ADRS. Record every input domain and verify domain separation: ∀ two distinct call sites c1 ≠ c2, ADRS(c1) ≠ ADRS(c2) ∨ the function type differs. If separation fails anywhere, report it as a finding.
State exactly which fields the adversary chooses in the forgery σ*: R, ctr, every revealed FORS value, every WOTS+C value and counter, every authentication path. Verification must be the code's verification, not an idealization.
Deliverable 1: the game, the oracle-call table, the domain-separation table, and the list of adversary-controlled fields.

## 2. Point 2 — bound each term
Work in the random-oracle model with SHA-256 treated as a family of independent random functions per domain, and a separate step that lists the properties used (second-preimage resistance SPR, target-collision resistance TCR, decisional-PRF).
Let ε_t be the advantage terms below. Prove or compute each.

2.1 Secret derivations (PRF). Replace every PRF(sk_seed, ADRS) output by a truly random value: |Pr[A wins] − Pr[A wins in the hybrid]| ≤ Adv^{prf}(B1), with B1 making at most (number of leaves of FORS + WOTS+C chains + nodes touched by the signer) queries, an explicit integer. Prove the same for PRF_msg and the deterministic selection of R, and prove that determinism does not leak: ∀ m, R = f(sk_prf, m) is independent of what A sees across distinct messages.

2.2 FORS+C. Compute the success probability of the best forger per hash try: ε_F(q) = 2^{−a} · Σ_{r≥1} Pr[R = r] · (1 − (1 − 2^{−a})^r)^{k−1}, where R ~ Binomial(q, 2^{−h}) is the number of signatures on the same FORS instance. This is the quantity already computed (forsc_log2_forge, h = 41, a = 9, k = 18): 143.3, 132.6, 125.9 bits at 2^38, 2^40, 2^41. Show that the number of grinding tries available to A, N_try (a stated integer, e.g. 2^128 or the quantum equivalent), satisfies N_try · ε_F ≤ 2^{−128}·N_try-correct; state the exact claim: ε_F is the per-try probability, so the security level is −log2 ε_F minus the attack budget. Close the gap between "per try" and "total": define the total bound ε_FORS = (Q_H) · ε_F + ε_TCR(tree), with Q_H the number of hash queries; give Q_H = 2^{128}-equivalent budget and the resulting level.
Also prove the forced-tree claim: "the last tree is forced to index 0, so any signature on the instance reveals leaf 0" — check the code, not the text.

2.3 WOTS+C target-sum layers. For one layer with parameters (w, ℓ, S): a message digest x ∈ [0,w−1]^ℓ with Σ x_i = S. One signature reveals chain values at positions x; a forger can win iff the target vector y satisfies y_i ≥ x_i ∀i (chain values are computed forward) with Σ y_i = S, and y ≠ x. Because Σ y = Σ x = S, y ≥ x ⇒ y = x: one signature is an antichain, safe. For j signatures on the same key pair x^{(1)},…,x^{(j)}: y ≥ min_t x^{(t)} coordinate-wise is forgeable. Compute, for each layer, the number of distinct (leaf, message) pairs the signer can see: each hypertree leaf is used by many messages (the hypertree is addressed by a pseudo-random leaf index). Model: leaf index uniform over 2^{h'} at that layer, so the multiplicity of the same WOTS+C key follows Poisson/Binomial. Derive ε_W(layer i, q) = Pr[some WOTS+C key signed ≥ 2] · Pr[the forger finds a digest with y ≥ min x | two signatures], and the exact count with inclusion–exclusion (reuse the code of H1 rollback_reuse.py and CE-02 ce02_reuse_bits.py, but with LULA's parameters: S = 240, ℓ = 32, w = 16 and S = 2040, ℓ = 16, w = 256). Note: in the hypertree below the top layer the same WOTS+C key signs the same node value whenever the lower tree is the same, which is not a reuse; separate "same message" from "different message". Prove which case occurs for each layer.
Also prove the unforgeability of one-time use under SPR of the chain function (loss factor w·ℓ).

2.4 Merkle trees and hypertree glue. Bound the collision/second-preimage probability of the authentication paths: ε_tree ≤ (number of nodes) · Adv^{SPR/TCR}(H), explicit for each layer (nodes per tree 2^{h'+1}−1, trees per layer 2^{h − Σ lower}). Prove that a forgery either (i) reuses an honest node (reduces to FORS+C or WOTS+C), or (ii) contains a new node on some path, which breaks SPR. Make the case split exhaustive: ∀ σ*, (σ* shares the full path with an honest signature) ∨ (∃ first divergent node) — state it as a lemma and prove it.

2.5 Composition (hybrid argument). Prove
Adv^{euf-cma}(A) ≤ Adv^{prf}(B1) + ε_FORS(q) + Σ_{i=0}^{4} ε_W,i(q) + ε_tree + ε_H_msg,
where ε_H_msg covers collisions in the message hash and the adversary choosing R, ctr. Write each hybrid game H_0 … H_m, say what changes, and which term pays for the step. No hybrid is allowed to be an informal "similarly".
Compute the total in bits at q = 2^38, 2^40, 2^41, and the smallest q at which the total drops below 2^{−128}.
Deliverable 2: one table with rows = terms, columns = q, values in bits, each cell labeled PROVED/COMPUTED/CITED/ASSUMED, plus the proof text and the script that reproduces the numbers.

## 3. Point 3 — close the cache/rollback premise
The conditional theorem states: Sec(reference signer) ≥ λ ⇒ Sec(cached signer) ≥ λ − δ, where δ is the transfer loss. Now that point 2 supplies Sec(reference signer), restate the theorem with the number: for q ≤ q_max, ε_{cached} ≤ ε_{ref}(q) + δ.
Prove ∀ cache state c ∈ {empty, fresh, stale, corrupt-but-undetected}: the output of Sign(sk, m, c) = Sign(sk, m, ∅) when c is consistent, and Sign aborts or recomputes when c is inconsistent. Settle "corrupt-but-undetected": state whether the signer verifies the cached node against the root or trusts it; if it trusts, a corrupted node changes the signature and the verification fails (a liveness issue, not a forgery) — prove which. Check the claim that old snapshots give byte-identical signatures with a test over the cache file (done for 100/100 and 50/50; extend to a proof sketch with the code path).
Deliverable 3: restated theorem with explicit constants; the proof that the cache state is not an oracle for the adversary (the cache holds only values A could compute from pk and public data).

## 4. Point 4 — quantum security
Two levels. Do both; report which one is proved.
4.1 Reading (cheap, already in R6A): classical bound ε(q) with the attack budget replaced by Grover's quadratic speed-up: a classical search of 2^{b} costs ≈ 2^{b/2} quantum queries. State the resulting category-1 reading with the exact assumptions and without claiming a proof.
4.2 Proof in the quantum random-oracle model (QROM). Use the established tools: the one-way-to-hiding lemma, the semi-classical oracle technique, and the QROM results for hash-based signatures (SPHINCS+ in the QROM: Hülsing, Kudinov, Ronen, Eikenberg, et al. and the Kudinov–Nick ePrint 2025/2203 section on generic attacks). For each term of point 2:
- PRF → quantum-secure PRF: assume or cite.
- FORS+C, WOTS+C, Merkle: SPR/TCR in the QROM with a loss of about √(·) or a factor 2^{−b/2}; give the exact form from the cited theorem, not an estimate. The R6A record says the provable bounds lose about 10 bits; recompute from the formulas.
- Count quantum queries Q_q explicitly.
Conclusion form: ∀ quantum A with ≤ Q_q queries, Adv ≤ f(Q_q, q, parameters); find the largest q with f ≤ 2^{−64}-equivalent (category 1). If that q is below the classical q_max, the design limit must be lowered (likely to 2^38 or less).
Label: if only 4.1 is done, the paper may say "category 1 under the plain Grover reading, no QROM reduction". If 4.2 is done, state the q with the bound.
