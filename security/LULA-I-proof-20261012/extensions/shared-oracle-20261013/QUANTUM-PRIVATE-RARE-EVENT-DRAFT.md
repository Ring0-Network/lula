# Sharper event-specific private replacement — unreviewed candidate

**OPEN — not a replacement for the accepted distance lemma.** This candidate aims to remove its linear trace-distance loss from a rare winning event by stopping before source public/private aliases. It is a new proof obligation; no numeric master field uses it. The accepted theorem remains the conservative normalized trace-distance bound.

## 1. Stop before the exceptional honest/public hash

**ASSUMED — same finite model.** Fixed nonzero S, N=2^128, independent F/J/O0/K/P and the reviewed ordinary REAL coupling. Classical atomic services and final classical verifier are the only source operations; q initiated calls and Q coherent adversarial full-hash queries. Setup and addressed hashes cannot be private-family aliases.

**OPEN — stopped comparison.** Both comparison controllers inspect a public source I/E call immediately before hashing. If its raw input is in D_K or M_P, emit an absorbing classical alias flag B and stop BEFORE the hash response. At nonalias points REAL and ideal source handlers use the same O0 and private F/J values, including partial termination. The controllers are therefore common channels; the coherent public query operator remains their only discrepancy. This inspection is proof-side and reveals no new production API. Record the event W of final acceptance/freshness without B.

## 2. Active prefixes versus a key-blind unflagged continuation

**OPEN — smallest new lemma.** Generate the original continued JOINT-IDEAL interaction without acting on any analytical alias flag. K/P are unused by every query/local/source response in this continuation. Keep dephased request/response histories and inaccessible copies of measurements. For a fixed environment and complete classical history, the stopped ideal active prefix is the same unnormalized block multiplied by its 0/1 no-prior-alias indicator. It is a positive sub-block of the key-blind unflagged ideal prefix; it need not have uniform keys AFTER normalization.

If this domination holds at each packed numbered coherent-query slot, its averaged private-support mass is bounded by the unflagged prefix's 1/N. Inactive branches receive an identity/plus dummy query in both controllers. The difference of full256 XOR unitaries on the active private-support subspace has norm at most two, hence averaged squared local purified error <=4/N. Common stopped service dilations and product telescoping then give global vector gap a=2Q/sqrt(N). This is not inferred from normalized trace distance or survival-conditioned uniformity.

## 3. Two terminal event projectors

**OPEN — candidate square-root projections.** The terminal projectors B and W are common in the stopped coupled experiment. The unflagged key-blind ideal continuation nominates at most2q+2 P guesses in honest/final calls. Its first-alias event has probability at most b=(2q+2)/N, capped at one. The stopped ideal event W is a subset of the full continued ideal winning event, so p_I(W)<=epsilon_HJ. The common purified gap, if established, implies

    p_R(B) <= min(1,(sqrt(min(1,b))+a)^2),
    p_R(W) <= min(1,(sqrt(min(1,epsilon_HJ))+a)^2).

Faithful REAL execution agrees with the stopped REAL until B. Thus its full win probability is at most p_R(B)+p_R(W), giving the candidate bound

    epsilon_REAL_nonzero <= min(1,
        (sqrt(min(1,b))+a)^2
        +(sqrt(min(1,epsilon_HJ))+a)^2).

Average uniform S and pay at most1/N once. This would improve rare-event scaling at small Q, but still becomes vacuous at Q=2^64. It is not an attack, a category theorem or an efficient simulator.
