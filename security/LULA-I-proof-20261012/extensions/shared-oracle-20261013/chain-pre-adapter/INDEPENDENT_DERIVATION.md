**PROVED — manual, independent first derivation; awaiting a second reader.** This supplies a finite classical RO-relative preimage program for the first currently-unexposed genuine WOTS chain query in the ordinary joint-private ideal experiment HJ. It does not give a conventional SHA-256 PRE reduction or a QROM reduction. No new peer candidate was read before this file was saved.

## 2. Explicit primitive interface, not ordinary PRE identification

**ASSUMED — RO-relative selected-restriction PRE challenge.** B chooses S!=0 and an actual valid type0 address d before A starts. The challenger samples an independent uniform16-byte X and an ordinary random full256 function O_d on all finite payload byte strings in the bounded experiment. It supplies Y=O_d(X), all32 bytes, and `Selected(z)=O_d(z)`. The target input is hidden. Winning requires output16-byte z with Selected(z)=Y (full256 equality). The remaining complete-byte raw restrictions are sampled by B independently; the complete raw router on header S||zero48||d uses Selected, including payload lengths other than16, and otherwise its local raw table. The target header is exactly86 bytes. Off-length selected queries are answered normally but are not output candidates.

**PROVED — distinction.** This is an addressed random-oracle relative uniform-input PRE challenge. It includes the actual shared raw selected restriction and is not a separate keyed PRE function plus an unrelated raw oracle. Giving Y's lower128 limb is internal reduction information: A receives only source-defined public data and raw replies; B does not append Y to its transcript. A genuine hidden-input query produces full256 Y and thus suffices for this stronger fullimage win predicate, even though the signer normally retains only its upper128 bits. No statement identifies this challenge with fixed SHA-256 or an existing SM-PRE theorem without an interface lemma.

## 3. Selection and latent joint coupling

**COMPUTED — namespace.** The number of nonterminal WOTS type0 addresses is
D_W = 480*(2^41+2^36+2^31+2^26)+4080*2^21 = 1,089,588,072,284,160 < 2^50.
Choose j uniformly among the exact2^50 bit strings. Unrank j into the structured layer/tree/keypair/chain/position namespace; indices j>=D_W fail without running A. Every genuine address has probability exactly2^-50; there is no rejection loop and no invented D_W normalization.

**PROVED — construction at r=0.** Treat the selected ideal F secret's upper128 bits as the latent unknown X, and sample its unused lower128 limb independently. Never return that secret to B or A. B needs only the selected chain endpoint for PK construction, obtained by starting from U_1=first16(Y) and applying the ordinary subsequent chain restrictions. For a selected-chain honest signature at e>=1, derive U_e from U_1. An attempted completed disclosure at e=0 triggers failure before a response. No public F oracle exists in HJ, and source raw type5/type6 restrictions are independent of privatized ideal F.

**PROVED — construction at r>0.** B samples the selected ideal F word normally, knows U_0, and evaluates only steps0,...,r-2 to obtain U_(r-1). In a *latent joint coupling*, define the full256 preceding image at the one designated point of restriction d_(r-1) as (X,L), with independent uniform128-bit L. Then U_r=X and the selected image at d_r is precisely Y. All other points of that previous restriction retain independent ordinary full256 outputs. The predecessor function had not been used to choose U_(r-1), so assigning an independent uniform fullword at that input yields exactly its ordinary random-function law. The selected O_d is independent of both that earlier prefix and X. This construction retains the source joint law, including all lower limbs; it does not assert merely that U_r has a uniform marginal.

**PROVED — executable implementation.** B never tries to write the unknown X into an actual response. Its implemented public router checks the known complete input (header d_(r-1), payload U_(r-1)) and fails *before replying*. Thus the one latent differing table cell is never returned. At every other complete input the ordinary local raw table is a correct executable reply. Honest PK generation of the selected chain is intercepted by the endpoint/suffix shortcut from first16(Y), so it never requests the unknown predecessor image. An honest completed signature at e<=r fails before its response; at e>r its selected chain value is derived from U_(r+1)=first16(Y). This interception is a source-relative game adapter, not literal execution of an opaque Rust interpreter that expects a concrete Node at every internal step.

**PROVED — no-cut detection before the selected winning prefix.** Couple B to a full source HJ experiment by that latent construction. If tau has the selected address d_r, then no previous completed signature exposed a selected position <=r; otherwise r would already be in the permanently exposed suffix at tau. For r>0, the designated preceding input U_(r-1) was unexposed throughout that prefix too. An earlier public query at that preceding input would itself have been an earlier H_W, contradicting tau's selection. Therefore neither exposure-stop nor predecessor-stop occurs before tau. No other stop is introduced. A successful setup is unchanged because its endpoint/counter/public-node data are identical. A noncompleting source branch with no such tau contributes zero and cannot produce a late winning continuation.

## 4. Reduction B_PRE as a program

**PROVED — program.**
1. Sample exactly50 selector bits; dummy indices return failure. Fix S (or sample the ordinary production S and immediately fail if S=0), decode d_r, initialize the chosen-target challenge, and construct the selected prefix/suffix described above using lazy local F/J/O tables.
2. Run A's pre-key phase through the public router with S/pk withheld. Forward selected-header queries to Selected; forward other queries to local raw O, except the one predecessor-stop input for r>0. After each selected-header query of16-byte payload z, compare its returned32 bytes with Y. On equality output z and stop successfully. All other queries retain their exact ordinary reply. No query history is measured or changed except this classical early successful termination.
3. Retain A's continuation, run obligatory source setup with only the selected-chain endpoint shortcut, and give source pk and any allowed logical public payload after completion. Canonical counter exhaustion uses the source nonwinning totalization. Do not abort because an irrelevant unrequested canonical row fails.
4. Run A and each requested atomic source signature. The source routine's selected-chain endpoint queries are replaced by the same shortcut. If the selected chain would be disclosed at e<=r in a complete response, return reduction failure without giving that response. For e>r return its correct derived suffix value. Preserve all other source values, complete message processing, exact digests/counters and Seen bookkeeping. Repeated messages and snapshots reuse F/J/exposure state.
5. If A reaches the final signature, execute the exact final source verifier through the same router, checking root equality and parsing normally. Inline extraction still runs on its selected-header16-byte payload queries. Any selected-image full256 match outputs its payload and stops successfully; otherwise output failure after final verification. B is allowed to succeed even on a pre-key query or a transcript that later would not forge: this can only strengthen the upper bound on H_W.

**PROVED — quantitative statement.** For every fixed S!=0,
Pr_HJ[H_W | S] <= 2^50 * Pr_PRE[B_PRE wins | S].
For each source run with H_W, exactly one of the2^50 selectors designates tau's address. In that coupled run no earlier stop occurred, and tau's input X returns Y, giving a valid PRE answer. Other selectors can also win through a fullimage collision or earlier hit, so this is an inequality, not an equality. For the source H_W contribution to an accepting forgery the same inequality holds by event inclusion. If S is ordinarily sampled and B fails immediately at zero, then
Pr_source[H_W and S!=0] <= 2^50 Pr[B_skipzero wins].
If one instead uses conditional fixed/nonzero-S challenges, pay Pr[S=0]=2^-128 once in the master theorem, never once per component.

## 6. Why this does not yet close QROM or standard PRE

**PROVED — classical limitation.** A coherent query can have amplitude on the known predecessor-stop input. B cannot test membership and stop before replying while preserving that oracle query. The preceding full256 cell contains the unknown X, so answering it coherently cannot be implemented by the same stopped classical program. Running the same check in a superposition is a measurement/projection and changes the experiment. An O2H/hybrid bound could charge that change, but its exact projector/error and query resources require a separate lemma.
