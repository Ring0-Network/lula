# Context lifting clarification, saved before peer read

My first540ae17b is preserved unchanged. This refinement was derived after its save but BEFORE reading the fieldb077 message-hash proposal.

Source-derived context does not require an independent random-root challenger. Define a public virtual family with logical message x=Enc(S16,T16,M), an injective bounded encoding. Its evaluation PARSES x and calls the SAME original literal hash words h(R||S||T||M), then h(U||BE32(c)||S). Tags/lengths used by Enc are not hashed in place of those source words. R alone is the uniform target key/nonce; S and T are chosen input fields, fixed before that R is drawn. B computes its source S/F/h-root setup privately, retains the correlated F state, and submits x for every fresh message. This is legal chosen-message chronology and does not presume T is independently uniform or let B reconstruct F for an unrelated challenger root.

For explicit cross-context set separation, primitive tuple labels may be tagged(p,I,j,J_j); one fixed source context then gives exactly the original indexed coverage predicate. If an ordinary MAP output embedding is desired, prefix the virtual function's ROUTE FIELD with p, making its route width297 rather than41. That public wrapper output tag is not an extra source hash byte or an independent raw domain. It changes the named primitive instance/map parameters and forbids pretending a source h41 uniform-RO formula already applies to that297-bit lifted route. These context tags are optional for the source-specific single-context reduction, but useful for a general chosen-context family.

The named additional asymmetric property can therefore use Target(Enc(p,M)) -> fresh R, firstaccepted c0/fullD, or bottom; Final(Enc(p*,M*),R*,c*) may use any accepted c*. B caches first responses per Enc(p,M), so the nonmemoized fresh-nonce oracle realizes ideal J for the fixed source p and repeated bare M. All target and candidate digests are evaluations of one known fixed h. Source fresh M ensures logical input/pair freshness for p*=p.

This removes the need for a separate independent-uniform-root assumption in the EXPLICIT chosen-context lifted property. It does NOT identify the original unlifted primitive with the source, repair the canonical-target/arbitrary-counter asymmetry, prove lifted-property hardness, or transfer published random-function ITSR numerics. Registered-context RC-CTAC-SR in the first remains a sufficient explicit formulation; the lifted variant is a less cumbersome legal interface for the same conditional source program.
