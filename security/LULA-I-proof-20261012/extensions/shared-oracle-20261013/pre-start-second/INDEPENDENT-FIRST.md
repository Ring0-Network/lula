## 1. Subject and primitive

**ASSUMED — explicitly supplied source game.** HJ[h] uses one fixed, public, complete algorithm h returning 256 bits, available unchanged for classical or coherent computation. It has independent persistent private F: valid ADRS22 -> Node16 and J: complete message bytes -> Node16. F/J give independent uniform 128-bit values at distinct labels. The source public seed S is uniform Node16 independently of F/J; the actual public root is computed by source key generation. Secret seed fields are independently sampled according to the source distribution, but their source PRF calls are replaced by F/J in this hybrid. Source secret fields are not revealed. Honest logical cache exposure comprises generated nodes and counters, not a seed-bearing driver persistence fixture. Restores reuse the same F/J and permanent exposure bookkeeping.

**CITED — HK22 Definition 3, printed page 5, cached text 188–196.** The challenger samples P first. Stage B1 chooses distinct tweaks and receives Th(P,d,X) for fresh independent uniform secret inputs X, without receiving P or X. B2 later receives P and can return any preimage M satisfying the target image equality; it need not return the originally sampled X. Definition 7, printed page 6, text 241–268, additionally gives B1 classical collection-oracle access with disjoint challenge and collection tweaks. Neither definition gives X to B, nor a signing or source-graph service.

**PROVED — applicable member.** Define Th^h_128(S,d,x)=prefix128 h(S || zero48 || d || x), for |S|=16, |d|=22, |x|=16 bytes. This is the source's first type-0 WOTS image or height-zero type-3 FORS image, from lib.rs 124–177, 255–268, 345–353. Th is a deterministic publicly evaluable member for the actual public h. Its PRE target Y is 128 bits. No unused private 256-bit limb exists here. One public h algorithm handles every domain and every payload length; nothing is replaced by a second hash oracle.

**PROVED — chronology.** B1 need not run the source adversary's pre-key phase. It can select a source coordinate independent of S, obtain its one PRE target, and terminate. B2 receives S, runs the source adversary's entire pre-key phase with S and the root withheld from that adversary as the source game requires, then performs setup and all later phases. Internally knowing S does not disclose it to the source adversary. That adversary still uses the same public h algorithm, so it can query guessed seeds or compute h coherently during this pre-key phase. Nothing about those computations is simulated by an unrelated oracle. B1 uses zero collection queries: Definition 7's disjointness condition is therefore automatic, and all subsequent source public hash calls occur in B2.

## 3. Legal opaque-start simulation

**PROVED — latent coupling for either selected start.** The challenger input X is a fresh uniform Node16 independent of S and the other F/J labels. In the mathematical coupling define the selected F value to be X. B's executable F table stores an opaque marker at that private label, rather than X. It samples every other private F label and every J label independently and persistently. This changes no public h cell or circuit. The node Y returned by PRE is exactly the first source typed-hash image of the selected start.

**PROVED — selected WOTS position zero.** Whenever honest internal computation would obtain this F value and evaluate chain step 0, start at position 1 using Y instead, then compute positions 1 onward with the unchanged public h. WOTS endpoint construction, public-key compression, Merkle generation and the actual hypertree root follow normally. A requested signature at selected digit e>=1 is computed from Y using e-1 additional public typed hashes. A signature at e=0 would return X, and is handled by the completed-response exposure guard below. No literal source internal call receives unknown bytes X: the adapter replaces the selected chain routine by the equivalent known-image suffix routine. For selected starts not reached by setup, the marker and image are sufficient; no unnecessary subtree or FORS instance is built.

**PROVED — selected FORS secret.** Replace the selected leaf's private-F-and-height-zero-image pair inside Fors::tree (lib.rs 345–353) by leaf image Y. All other leaves, ordered internal nodes, tree roots and FORS root compression are generated normally. Signing a different index returns its ordinary secret plus authentication path; that path can contain the selected leaf's image Y or ancestors computed from it. It never requires X. Signing the selected index would expose X and invokes the completed-response guard. The signer need not materialize that unknown secret during tree construction or private calls.

**PROVED — actual distribution, not a marginal substitution.** For fixed h and S the source public graph is a deterministic function of its independent F/J values and source seed fields. In the coupling its selected F value is exactly X, not a separately sampled input whose image is forcibly identified with Y. Replacing evaluation of Th(S,d,X) by its genuine target Y therefore produces the exact same endpoints, node vectors, canonical counters, pk.root, signing digests and logical cache payloads on all simulated complete branches. Collisions of h or collisions between F values do not invalidate this identity: the program retains the public h and does not condition on distinct values. X is uniform before exposure, not asserted uniform conditioned on the public root or cache.

**PROVED — complete response / atomic partiality.** The source signer accumulates output locally and returns it only at lib.rs 666–667; it does not stream intermediate secret fields. The simulator may assemble a signature with opaque slots. It completes all required counter searches, public node computations and acceptance checks first. If a completed response contains the selected FORS secret, or a selected WOTS position-zero digit, it stops with reduction failure before releasing any part of that response. Other responses are released atomically with exact source bytes, and only then update Seen/exposure. A source setup/signing computation that fails or does not complete is an absorbing nonwinning branch under the supplied game totalization; the simulator follows that branch, with no response and no success normalization. Guards based merely on an intermediate attempted disclosure do not establish this atomic-prefix claim.

**PROVED — honest cache / local API guard.** The selected unknown start is never a field of LayerCache: `subtrees` contain WOTS public-key leaves and public Merkle nodes, and `ctrs` contain canonical counters (lib.rs 448–451,538–563). These are computable from Y. The actual logical cache can therefore be returned with its source distribution. A fixture that saves seed bytes or an API returning Signer.ctx secret fields would break this simulation; it is excluded by the stated HJ model, and cannot be silently conflated with honest cache exposure.

## 4. Event extraction and inequality

**CITED — event binding only.** CHANGED-CHILD-EXTRACTION.md lines 11 and 19 define H_final at the final verifier's classical queries, indexed by complete address and coordinate, against permanent honest exposure/forward closure. Actual acceptance compares the verifier result to the actual public root (source lib.rs 672–674). Define H_start,final as the subevent where a reached final verifier query uses a genuine unrevealed FORS secret or WOTS position-zero input. It does not include interior WOTS positions.

**PROVED — B2 program.** Run the above source setup and signing simulation, letting the source adversary compute the unmodified public h, including coherently. At its final classical signature/message execute the source verifier, retaining classical typed-hash inputs. At any reached selected type-0 position-zero or selected type-3 height-zero query with input z, compute Th(S,d,z) and compare with Y. If equal, return PRE target index 1 and z. Otherwise return failure after verification. The output may be an alternative preimage: HK22 permits it. No h computation inside the quantum adversary is inspected, measured, redirected or tested for the original X. The ordinary classical final verifier supplies an output candidate already in the classical transcript.

**PROVED — no abort on a selected winning branch.** On a source run with H_start,final, choose the first eligible final query as a deterministic witness. If the selector chooses its label, no prior completed honest response exposed that start, by the coordinate-indexed event definition. Hence the complete-response guard never aborts that coupled execution before the witness. Setup and all honest logical caches have exact coupled values. The witness query supplies z=X and therefore Th(S,d,z)=Y. Extraction succeeds even if other selectors additionally succeed on alternate preimages or nonforging transcripts.

**PROVED — pointwise selector averaging.** For every source adversary A (classical or quantum with classical signing interface), there exists the specified two-stage one-target PRE adversary B with

Pr_HJ[h][Win AND H_start,final] <= Pr_HJ[h][H_start,final] <= 2^55 Succ_SM-PRE(Th^h_128,1;B).

The coupling is unconditioned on source success. Uniform source S is exactly the challenger's uniform P. There is no source-zero exception needed by this local uniform-start proof: its addresses and encoding are well-defined also at S=0, and F/J independence is a supplied hybrid premise for all seeds. If a parent hybrid only covers nonzero seeds, that parent restriction must be carried separately; this proof does not establish the earlier private-function hybrids. An exact uniform selector over D_0 with rejection sampling can replace 2^55 by D_0 at its own variable-time selection cost; the fixed 55-bit selector avoids that cost.

## 5. Source-relative resources

**COMPUTED — private labels.** Top-cache setup touches 2^21*16 top starts and 2^21*32*32 layer-3 child starts, hence 2,181,038,080 distinct F labels. A hot signature has at most 17*512+4*32*32+16=12,816 distinct F labels; selected FORS returned secrets and WOTS starts are repeats within those subtrees. A cold signature adds the top subtree's 2^21*16 starts instead of only its selected 16, giving 33,567,232 distinct F labels. J has at most q distinct complete-message labels. F dictionary cap is min(D_0,2,181,038,080+q*U_mode); the selected opaque slot adds constant metadata even if never source-touched, not a new independent sampled F value. Source secret sampling is not counted as a hash operation.

**COMPUTED — conservative complete-h caps.** Count complete public h calls, not compression operations. A lower WOTS subtree costs 32*(32*15+1)+31=15,423 calls. The top WOTS tree costs 2^21*(16*255+1)+(2^21-1)=8,560,574,463 calls. Top-cache setup costs H_setup=2^21*(19,505+2^32)-1: each leaf costs 4,081 endpoint/compression hashes, 15,423 child-subtree hashes, and at most 2^32 grind hashes; upper Merkle hashes add 2^21-1. One complete signing response has H_hot=82,090+5*2^32 or H_cold=8,560,574,463+82,090+6*2^32 as conservative caps. These include actual complete message inner hash, outer counter search, FORS tree work, canonical lower WOTS searches, final digest checks, paths and WOTS signing steps using the accepted sums 240/2040. One final verifier uses <=3,224 complete h calls: 2 message calls + 171 FORS calls +4*247 lower WOTS/path calls +2,063 top calls. Every finite u32 counter row has at most 2^32 tested values under the supplied nonwinning totalization; this is an explicit finite bound, not a feasible-runtime claim.

**PROVED — B resources.** B1 uses exactly one PRE challenge call and zero collection-oracle calls on a genuine selector, and no source setup. B2 uses source simulation work plus <=3,224 final verifier calls and constant target comparisons; known-image shortcuts remove calls instead of adding them. If Q_h counts A's public h computations, a conservative total is Q_h+H_setup+q*H_mode+3,224. The public h quantum circuit stays untouched, so A's quantum query/computation accounting is carried unchanged. Memory includes real source tree/cache allocations, F/J dictionaries, message/signature bytes and a constant-size selected marker/image/address; it is not merely constant memory. Enumeration of D_0 is unnecessary. The ordinary PRE assumption must be evaluated at this actual time/space/query budget; no feasible wall-clock estimate or cryptographic security number is inferred from these expressions.

## 6. Exact remaining boundary

**PROVED — interior predecessors excluded.** A WOTS interior input U_r for r>0 is generated by h from previous source values. It is not an independent private F output in HJ[h]. Even a uniform marginal in a different random-oracle experiment would not license embedding an unknown uniform challenge input into its public predecessor cell. Such an embedding would require changing h or answering an unavailable predecessor output. This start lemma never performs either action.

**OPEN — smallest missing lemma for the rest of H_final.** Supply a lawful fixed-public-h interface that handles the joint h-generated interior trajectory and any relevant later exposure, rather than declaring the interior U_r equal to an inaccessible ordinary uniform-input challenge X. Without that lemma, the ordinary PRE reduction above covers only H_start,final. It does not cover arbitrary hidden quantum query amplitudes, the whole H_final event, or final interior predecessors.

**OPEN — independent composition obligations.** This adapter proves a source-relative uniform-start inequality in the ideal F/J hybrid. Establishing the F/J hybrids, all other event components, complete composition and resource-suitable primitive advantages remains separate work. No SHA security number, category, random-oracle scalar transplant or implementation security claim is made.
