**PROVED — localized successor to the independently derived WOTS program.** This addendum extends `INDEPENDENT_DERIVATION.md` (SHA61a8c1d673008b83ba61887d762ad0e51501de039ef870b8b5a43eae7b73e0fa) to the whole H event, while preserving its classical, fixed-nonzero-S and RO-relative boundaries. **COMPUTED — exact FORS source addresses.** `Fors::real_trees` uses17 trees. Each instance has17*512 secret starts. Its indexed instance space is2^41, so D_F=2^41*17*512=19,140,298,416,324,608. A height-zero leaf image uses type3 address `(layer0, tree, kp, height0, globalIndex=j*512+i)` and its private ideal F secret uses distinct type6 address `(layer0, tree, kp, 0, globalIndex)`. The source tree loops exactly those real indices. The omitted eighteenth coordinate contributes only the digest zero filter and has no secret start.

**PROVED — selected FORS secret adapter.** Select one such height-zero type3 address d. Use the same uniform16-byte hidden input X and full256 target Y=Selected(X). Put X symbolically into the corresponding type6 ideal F word's upper128 limb, with independent lower128 limb. The executable simulator does not request or return X. In `Fors::tree`, replace just this one leaf's secret derivation/image computation by the known first16(Y); sample all other F words and build the ordinary leaf/internal nodes, roots and compressors normally. Consequently every public root/authentication node has exactly its source distribution. If a complete honest signature would transmit that indexed secret, stop with failure before returning the atomic response. An honest signature on another leaf can return its source secret and path: a sibling node that contains the selected leaf uses its known public image, not X. There is no unknown predecessor-cell stop in this case. Pre-key and final public Selected queries are served normally; on a16-byte input with full256 response equal Y output that input and stop successfully. No challenge service simulates full FORS instances or signing.

Use the localized WOTS stopped-cut adapter or this localized FORS secret adapter accordingly. Neither branch needs to enumerate any other hidden coordinates or detect arbitrary other hidden hits. If the source's first H query has the selected label, no earlier completed response exposed that label. For a WOTS branch an earlier direct-predecessor query would itself have been an earlier H, and therefore its stop cannot occur before this selected first hit.
