# Challenge-interface and finite-control clarification

**PROVED (interface boundary).** The first-hit adapter can simulate outside raw restrictions itself from independent residual tables plus ghost designated points. It does not require or claim it can reprogram an externally supplied opaque Raw_out. In a conventional single-function PRE challenge, other simulated RO restrictions are part of B's local environment; a symbolic entry at the predecessor is never emitted before B aborts. In a joint challenge that externally fixes every nonselected function and permits evaluation only, that interface is insufficient for this construction without an additional embedding lemma. The fact the conceptual outside function has the honest marginal does not confer oracle-programming access on B.
