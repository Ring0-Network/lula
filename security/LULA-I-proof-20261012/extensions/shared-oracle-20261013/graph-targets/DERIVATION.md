# Typed honest-graph targets: independent statistical derivation

**PROVED / OPEN verdict.** A classical random-oracle target-hit lemma is available for the fixed honest **type 0,1,2,3,4 graph** under the explicit acyclic input-generation hypothesis below. It has a query loss rather than a total-node multiplier. It does not apply unchanged to type 7, arbitrary self-selected targets, unaddressed message hashing, quantum queries, or full forgery security. This is a statistical ghost-graph result, not an efficient SPR challenge embedding.

## 1. Exact fixed graph

**COMPUTED (binding).** The actual library is `publications/LULA-I/release/code/lula1/src/lib.rs`, SHA-256 `ac8e67f05af68dd8e1291c5909847f74103903fb7ffa2c70f500c6ec48f14210`. Its address type constants are at 60–67, fixed 22-byte encoding at 69–95, and raw hash encoding at 121–147. All statements below concern the single-root fixed LULA I parameter set, not arbitrary caller parameters or mutable `bind_digest_to` use.

**ASSUMED (hash model).** SHA-256 is one shared random oracle O with 256-bit images; nodes take the first 128 bits. For S=PK.seed and address A, define `O_A(x)=O(S||zero[48]||A||x)`. Distinct A give disjoint raw input languages, because the header is exactly 86 bytes. This is independence of restrictions of a single oracle, justified by injective fixed headers, rather than independence by routine name.

**PROVED (source inventory).** Fix the complete mathematical honest graph from the key, whether or not every node is ever generated by a practical signing call. Its selected domains are the valid full addresses of types 0–4. Each has exactly one designated honest payload X_A and image Y_A:

| Type | Domain coordinates | Unique designated payload | Source / predecessor domains |
|---:|---|---|---|
| 0 | `(layer,tree,kp,chain,position)` with position 0…w−2 | honest chain value at that position, 16 bytes | 239–245; private type-5 start, then strictly earlier positions |
| 1 | `(layer,tree,kp,0,0)` | ordered concatenation of all chain endpoints | 251–262; type-0 chains of that key |
| 2 | `(layer,tree,0,height,parent_index)` | ordered pair of honest children, 32 bytes | 291–306; type-1 leaves or strictly lower type-2 heights |
| 3, leaf | `(0,tree,kp,0,global_leaf)` | private type-6 leaf secret, 16 bytes | 348–351; private derivation only |
| 3, internal | `(0,tree,kp,height,global_parent)` | ordered pair of honest FORS children, 32 bytes | 359–365; strictly lower type-3 height |
| 4 | `(0,tree,kp,0,0)` | ordered concatenation of the 17 real FORS roots | 370–394; type-3 roots |

**PROVED.** FORS indices are global within a fixed height: `j*2^(a−height)+local`, so the 17 component trees do not reuse one type-3 address at that height. Distinct heights have different addresses. The omitted eighteenth tree has no target domain. WOTS endpoints are fixed full chains, independent of the digit vector used by a particular signature. Signing shorter chain prefixes and later completing them repeats the same designated payload at each visited position. Rebuilding a subtree repeats the same pairs and endpoint strings; it does not create a second honest payload in those domains.

**PROVED (DAG).** Draw the private type-5/type-6 start values from their outside-domain oracle restrictions, or from independent private maps in the joint ideal game. They precede all selected domains. Compute full WOTS chains in position order, compress endpoints, build Merkle trees in height order, and compute FORS leaves/parents/root compression in height order. Separate forests and layers can be ordered arbitrarily where independent. A selected payload depends only on outside randomness and predecessor designated images, never on its own O_A restriction or a non-designated response. WOTS child values/counters are not used to build WOTS PKs. Their type-7 searches therefore introduce no dependency cycle into this selected graph.

**PROVED (private-source variant).** In the complete-hash RO model, actual type-5/6 derivation points belong to outside selected domains. Their outputs may be generated from the common secret seed, but their raw addresses are distinct and do not consult a selected type-0…4 restriction. This graph lemma does not itself need to infer secrecy or pseudorandomness from these starts. It may condition on all outside randomness and even those start values. Such conditioning is useful for a collision term but grants no complete-signature security.

## 2. Abstract finite-DAG theorem and correct oracle marginal

**ASSUMED (exact hypothesis).** Let D be a finite set of typed domains with a fixed topological order. Let Z be outside randomness independent of all their raw oracle restrictions. For each domain d, its designated payload is

    X_d = f_d(Z, ((X_e,Y_e)) for predecessors e<d).

The rule does not inspect any value of its own restriction or any non-designated selected-domain output. One domain has one designated target; repeated execution of its honest rule returns that same pair. Payload lengths may differ between domains but their raw headers are disjoint.

**ASSUMED (seed selection).** Fixed key coins, or uniformly sampled key coins, are chosen independently of the selected oracle restrictions. A caller choosing its seed after inspecting those restrictions is a different experiment and cannot be included by silently treating that seed as independent outside randomness.

**PROVED (eager ghost sampler).** Sample Z. In topological order calculate X_d and sample a fresh independent full 256-bit image V_d; set Y_d=V_d[0:16]. After generating the complete graph G, for each domain define its oracle restriction by assigning V_d at X_d and independent full uniform images at every other payload. Keep the entire outside oracle consistent. The full 32-byte designated image is sampled once, so a raw query at a designated point returns the correct extension of the exposed 16-byte node.

**PROVED (marginal).** Conditional on predecessor restrictions and Z, X_d does not depend on its own restriction. Assigning an independent uniform image to that one payload and independent uniform images elsewhere gives exactly an ordinary random function at domain d. Its distribution is uniform regardless of the chosen X_d. Induction over domains gives the correct joint marginal: all selected restrictions are independent random functions, independent of the outside randomness, and G is their actual honest graph. This is eager sampling, not overwriting responses from an already answered oracle.

**PROVED (residual independence).** Conditional on G and Z, every selected-domain value at a non-designated payload remains independent uniform 256-bit. Downstream designated inputs may depend on earlier designated images, but never read the earlier restriction's non-designated values. Exposing downstream nodes therefore does not constrain those residual values. Sampling residual tables only after G makes this fact explicit.

## 3. Adaptive target hits, graph exposure and prequeries

**PROVED (event definition).** A target hit is a query at selected address d and payload x≠X_d whose truncated image equals Y_d. It is an alternative input for that exact designated image, not a generic collision between two new inputs or a cross-address image equality.

**PROVED (one-query probability).** Expose the entire designated graph, including payloads and full designated images if desired. Let the adversary choose a fresh non-designated raw query adaptively from this information and previous responses. Its fixed header identifies at most one selected domain. Its residual full image is uniform independent of the chosen domain's known target, so its conditional hit probability is exactly 2^-128. The number of other target addresses does not enter this probability. A repeated previously unsuccessful non-designated point adds no new opportunity; a prior hit already accounts for the event.

**PROVED (union bound).** If at most B fresh non-designated selected-domain points are evaluated, the probability of at least one target hit is at most `min(1,B/2^128)`. This holds for an adaptive selection among all graph addresses and after observing all graph images. It does not justify comparing each new output with every target at unrelated addresses, which is a different event.

**PROVED (prequeries).** Sample the mathematical ghost graph and all tables at time zero. A real adversary may make raw queries before key disclosure or before an honest node is actually computed; these are still queries to the same already-sampled function. They must be counted in B if non-designated and eligible for a selected domain. Revealing G at time zero only gives a collision adversary more information. It does not authorize programming a later designated target over a previous raw reply. The full correct joint marginal established in §2 preserves the distribution of pre-key queries, even though their future selected header may not yet be known to the adversary.

**PROVED / boundary.** The original source adversary need not receive G: conditioning on it or bounding a stronger graph-exposed target-hit game suffices for this event alone. Giving all designated payloads to a signature adversary reveals all chain starts and FORS leaf secrets, allowing ordinary fresh-message signing without any alternative-input collision. Therefore this exposure **cannot** be substituted into the complete EUF-CMA experiment or used to claim every forgery produces this event. It is only a robust upper bound for the structural target-hit branch.

## 4. Source query accounting

**PROVED (honest selected hashing).** Honest key graph generation and signing, with honest cached or recomputed nodes, evaluate selected types 0–4 only at their designated payloads. Private derivation types 5/6 and WOTS digest type 7 are separate. Under nonzero S, unaddressed inner hashes cannot match a selected header because bytes 16–31 equal S rather than zero; outer hashes have length 52, shorter than the 86-byte header. Thus ordinary honest message/hash grinding does not secretly add selected residual evaluations in that branch.

**PROVED (final verifier bound).** For fixed LULA I parameters, the final verifier evaluates at most **3,217 selected-domain hash invocations**:

    FORS leaves / paths / roots: 17(1+9)+1 = 171
    four lower WOTS chains / PK / paths: 4(240+1+5) = 984
    top WOTS chains / PK / path: 2040+1+21 = 2062
    selected total = 3217.

The five type-7 digest checks and two unaddressed message hashes give 3,224 full-hash invocations for a valid signature. This is distinct from 3,265 instrumented / 3,266 executed SHA compressions for a 32-byte message. Target-sum rejection occurs before that layer's chains, so malformed inputs cannot increase the selected maximum. These counts concern the verifier's own calls, not additional raw adversarial calls counted in Q_public.

**PROVED (conditional classical structural term).** On nonzero S, with at most Q_public adversarial raw queries and one final verification, a valid target hit in types 0–4 has probability at most

    min(1,(Q_public+3217)/2^128).

Counting all raw adversarial queries is conservative; only fresh non-designated selected-domain points actually contribute. With a uniformly sampled S in the unconditioned experiment, charging the entire S=0 branch gives the safe bound `min(1,(Q_public+3218)/2^128)`. This is not a normalized setup-success-conditioned result; different conditioning/exposure interfaces require their own argument. No honest total-node or signing-query multiplier is inserted merely for computations at designated points.

## 5. Where one-target reasoning fails or does not apply

**PROVED (type-7 exclusion).** `WotsC::digest` uses a fixed type-7 address and the variable payload `V||BE32(c)` (216–236). Canonical grinding evaluates multiple payloads at the same address and selects the first accepted counter using that address's own restriction. There is not exactly one honest input there, and the selected-target rule is not the acyclic own-restriction-blind rule above. A separate stopping-time/canonical-counter lemma may be possible, but this DAG theorem proves none of it. In particular it must handle prequeries, the accepted fixed-sum distribution and noncanonical counters separately.

**PROVED (unaddressed exclusion).** PRF_msg and inner/outer message inputs do not have injective typed headers by routine name. Their overlap and adaptive routing obligations are not solved by selected public address separation. They remain on a shared oracle; the statistical term above cannot replace the shared-oracle privatization/coverage analysis.

**PROVED (counterexample without the DAG hypothesis).** Let one domain have three payloads {0,1,2} and binary outputs. Inspect all three own-domain values; choose the first payload x whose image equals the image at `(x+1) mod 3`. Such an x always exists. Expose the designated x and image. One new adversarial query at `(x+1) mod 3` hits the designated image with probability one, exceeding the naïve one-query 1/2 bound. Only one designated target was exposed; failure comes from selecting it by consulting other values of its own restriction. “One target per address” alone is insufficient.

**OPEN (efficient simulator / SPR challenge embedding).** A finite graph here is enormous. A ghost sampler may condition on its entirety, but an efficient reduction must pay for actual graph construction, private-oracle calls, memory, counter search and challenge placement. The pointwise RO event bound does not produce an efficient standard-model SPR/TCR adversary or a PPT runtime guarantee. Quantum queries are also outside the one-classical-point argument.

**OPEN (full composition).** Full forgeries can reuse honest node/endpoint values without a type-0…4 alternative-input hit. Hidden derivations, unexposed chain values, target-sum message binding, FORS coverage, unaddressed routing and the actual verifier classification still require their own terms. The structural event can be bounded statistically in the stated RO game even while a general efficient challenge embedder remains open; neither fact closes complete LULA security.

**Final status.** The proposed no-total-node-multiplier bound is justified for the restricted acyclic selected-domain target-hit event, with explicit full-function marginals, prequery counting and verifier work. It is invalid as an unrestricted single-target theorem and deliberately excludes type 7. The accompanying finite control checks both a two-domain DAG and the own-restriction counterexample.
