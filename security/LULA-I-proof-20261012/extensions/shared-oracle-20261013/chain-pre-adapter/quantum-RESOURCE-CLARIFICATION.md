# Coherent outside-table resource clarification

**PROVED — fixed function across every query interface.** The quantum candidate's local outside function O_B is one sampled complete256 table shared by coherent queries, honest classical source evaluation, suffix preparation, and final classical verification. An honest or final lookup does not sample a fresh independent lazy raw reply. It retrieves the same indexed32-byte table entry. Snapshot/restore bookkeeping leaves that function fixed. Selected-header calls use the same challenger Selected function on all payload lengths and phases. Full lower limbs are never resampled.

**PROVED — initialization charged.** Let b be the explicit finite maximum outside raw input byte length and V_b=sum_(ell=0)^b256^ell. An injective length-sensitive lexical index places every byte string in0,...,V_b-1. Initializing the eager table samples256V_b independent random bits, stores32V_b bytes and performs O(32V_b) byte writes, in addition to loop/index arithmetic. These are explicit startup time/storage costs, not free precomputation. Unused selected-header shadow entries are harmless extra costs. Sampling fixed outside tables before A preserves pre-key quantum correlations and independence from the blinded prefix variables.

**PROVED — shared evaluation costs.** Every coherent outside call uses the reversible lookup circuit for this same fixed table; the stated linear-scan O(V_b*(b+32)) gate envelope is conservative and does not assume QRAM. Honest classical raw lookups can use the fixed table by index, paying indexing O(b) plus copying32 bytes in a unit-cost addressable-memory model; a fully circuit-based implementation can instead use the same slower scan, still finite. Both choices retain function identity. Source F/J maps are distinct independent private functions accessed only classically, so their separate lazy memoization is valid. It is not a method of lazily measuring or servicing the coherent outside raw oracle.

**OPEN — optional efficient successor.** A2T-wise family may give an exact efficient bounded-query replacement, but that separate lemma must count all honest and classifier function evaluations as well as Q_q, preserve the coupled selected-prefix event, provide an injective byte-string domain encoding and charge its initialization/evaluation costs. No such replacement is silently applied to this eager-table theorem or existing scalar bounds.
