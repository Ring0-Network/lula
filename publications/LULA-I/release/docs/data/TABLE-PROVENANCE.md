# Table-by-table provenance

The manuscript has 21 labelled tables, including its qualitative claim-to-falsifier table. This map distinguishes reaggregation of raw measurements, recovery of surviving aggregate assertions, specification arithmetic, and qualitative claims. A parser or successful run does not turn one evidence class into another. Labels identify the table independently of page and line changes during final layout.

| Table label | Input and derivation | Reproducibility status |
|---|---|---|

| `tab:wire` | Fixed parameter tuple, serialized field lengths, cumulative zero-based offsets, and 5,720-byte public vectors. | Derivable encoding arithmetic; vector length cross-check available. No timing claim. |
| `tab:work` | Implementation-specific hash-count decomposition with the fixed parameters; retained full-parameter vector/replay compression count 3,265 excludes one prefix block. | Source-derived arithmetic and counter assertion, distinct from a fresh counted verifier execution. The unnumbered parameter-summary grid belongs to `tab:params`. The unnumbered D1–D6 digest listing is provenance, not a measured table: compare its hex bytes with the first-campaign and follow-up `binary-digests.txt` files. Digests identify historical files; missing binaries or build inputs cannot be reconstructed from a digest alone.

Portable raw-data outputs are generated by `analyze.py`. Model/specification and manuscript-cell acceptance checks are supplied by the separate release model and table-check scripts. The legacy `integrate_comparison.py` and `integrate_stability.py` also write manuscript files and must not be treated as read-only data-analysis entry points. Their old editorial reconciliation templates additionally preserve prose, rather than generating every later scientific table from raw measurements.
