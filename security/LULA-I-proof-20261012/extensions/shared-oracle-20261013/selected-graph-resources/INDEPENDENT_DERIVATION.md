# Independent typed-graph and selected-point resource derivation

COMPUTED / PROVED / OPEN labels distinguish arithmetic, structural arguments, and unclosed cryptographic obligations. This file was formed from the release library, the actual measurement parameter declaration, and frozen `SOURCE_AND_COUNTS.json`, before reading any new selected-graph reduction candidate. No graph, cache, key or cryptographic transcript is generated.

PROVED. Counting concerns valid addressed vertices, not distinct numerical 128-bit outputs: collisions do not merge addresses. ## Strict dependency budgets for a selected vertex

PROVED. A type0 selected hash at step t in [0,w-2] has one private start and t strict public predecessors. After changing its output, the forward chain suffix uses w-2-t calls, followed by one type1 compressor and h type2 path calls: w-1-t+h strict public graph descendants. A selected type1 call needs ell starts plus ell(w-1) public predecessors; it has h type2 descendants. A selected type2 at height v needs 2^v ell private starts and 2^v[ell(w-1)+2]-2 strict public predecessors; it has h-v type2 descendants. These are exact dependency-closure vertex counts, not instructions to discard siblings from a complete source simulation.

PROVED. A selected type3 vertex at height v=0,...,9 needs 2^v private starts and 2^(v+1)-2 strict public predecessors; its strict graph descendants are 9-v type3 ancestors and one type4 compressor. A selected type4 needs 17*1023 public predecessors and 17*512 private starts and has zero descendants inside types0-4. Recomputing descendants requires their unaffected sibling inputs too. A readily available finite fallback computes the whole containing subtree/forest, rather than pretending the strict selected path is sufficient preprocessing.

PROVED. A changed layer-j subtree root is a canonical child message of exactly one layer-(j+1) WOTS key, if j<4. It changes that parent's type7 canonical search, but not the parent's independent WOTS public key graph. A changed FORS public key changes the canonical type7 search of one layer0 key. Thus, conditional on a simulator changing a graph output and restoring consistent source metadata, at most one additional canonical search of L=2^32 attempts is required. This does not establish that changing a challenge output is legal in any particular SPR experiment. Changed chain values can also change signatures at the corresponding key; a simulator must use the changed graph consistently.

## Exact uniform-selection loss

PROVED. Let V be a fixed finite address universe with |V|=G>0. Let a source-world transcript define a subset Bad of V, independently of a uniformly selected J in V. Then Pr[J in Bad | transcript]=|Bad|/G. If a reduction selects one deterministic witness v(transcript) in every winning transcript, Pr[Win and J=v(transcript)]=Pr[Win]/G. Consequently Pr[Win]<=G Pr[selected-witness success], provided the simulation stays distribution-identical up to the witness and its success test is exactly the selected property. This identity alone supplies no embedding, challenge sampler, programming permission, no-abort claim, or conventional SPR equivalence. If J changes the transcript law, conditioning on that transcript does not justify uniformity; an embedding proof must repair that dependency.

PROVED. G is not a power of two. An exact uniform finite-set sampler is a semantic primitive; rejection sampling has finite expected cost but no deterministic attempt cap. A strict fixed-random-bit adapter may instead sample 56 bits, map integers less than G to graph addresses and treat larger integers as dummy nonwinning selectors. Then each genuine witness has probability 2^-56 and the loss is 2^56=72,057,594,037,927,936 rather than G. This adds no oracle queries and uses exactly 56 random bits. It does not fix a missing embedding identity.

## Eager and lazy implementation resources

COMPUTED. An eager graph-only fallback evaluates each private type5/6 location once and each public graph vertex once. Thus its raw/private invocation sum is ND+G, and retaining full256 words alone requires 32(ND+G) bytes, before keys, inputs or dictionary pointers. Keeping only node projections costs 16(ND+G) bytes but is insufficient if a proof needs their lower 128 limbs or raw correlation. Computing canonical metadata at every WOTS key additionally uses at most L times the number of WOTS keys type7 evaluations and four bytes per stored successful canonical counter. An exhausted metadata search is recorded as unavailable, not an immediate global abort: an irrelevant key's failure must not abort a source experiment that never requests that key. Only when source setup/signing actually needs the exhausted key does it enter the existing nonwinning partiality. A one-bit unavailable flag per key adds at most U_W bits (or U_W bytes in a straightforward representation). No native Rust abort is invented.

PROVED. These are finite but enormous, security-parameter-dependent graph enumerations. They are not efficient cryptographic PPT reductions. A lazy source adapter can instead construct only accessed subtrees and forward/program a properly defined challenge restriction; the already accepted `PRIVATE-REDUCTION-PROGRAMS.md` supplies one such explicit finite adapter for the private hybrids, but not a graph challenge embedding. Its honest work and adversarial raw budget remain separate.

PROVED. For an eager finite-resource upper envelope, let E=G+ND+L U_W with U_W the number of WOTS keys. The eager implementation can retain optional full raw records, at most 630G+134ND+138L U_W payload bytes: graph words have input length at most 598 and output length 32; private addressed words have lengths 102 and 32; canonical type7 words have lengths 106 and 32. Dictionary keys, pointers, indexing, and allocator headers add O(E log(2+E)) bits. The metadata table adds at most 5U_W bytes for counters and unavailable flags, and selected-point/key/address state is bounded by a further O(G+ND+U_W) records. A balanced comparison dictionary implementation uses at most C E*599*(1+log2(2+E)) word operations for eager evaluation and bookkeeping, excluding costs of external oracle evaluation. An adapter may avoid storing rejected rows by relying on the external oracle's functional consistency, in which case the 138L U_W payload term is absent from simulator storage but not from its invocation cap. This is a finite envelope, not a measured RAM figure or an efficient reduction. When combined with a lazy source adapter, add its separately specified storage/runtime/raw-call envelope rather than replacing it by E.

Every requested q=2^24,2^30,2^38,2^40,2^41,2^44,2^50,2^64 is evaluated exactly in `INVENTORY.json`. Honest classical calls must not be relabelled adversarial quantum queries. These deterministic caps include abort prefixes. Signing capacity remains an independent security question.

PROVED. The combined G+ND eager count must not obscure interface charges: in the REAL source all ND private restrictions are raw calls; in B_K they are at most ND Derive calls, with G public Raw calls; in B_P/GKP, the ND private words are independently generated local F samples, with G public Raw calls. Type7 preprocessing adds at most L U_W ordinary Raw calls in each case. Source service caps listed above can be added as conservative caps if the source adapter reruns those services; full memoization may decrease calls but never requires treating local F samples as adversarial raw queries.

OPEN. This inventory closes arithmetic and exposes honest resource costs. It does not certify a conventional selected-point SPR/PRE/TCR challenge program, oracle-programming permission, quantum access preservation, native Rust refinement, fixed SHA-256 security, or a NIST category. Any proposed selected-graph reduction will be checked separately against these exact counts and partiality boundaries.
