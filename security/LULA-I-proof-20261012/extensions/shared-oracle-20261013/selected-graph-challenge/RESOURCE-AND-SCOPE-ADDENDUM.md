A binary rejection implementation uses b=ceil(log2(D))=56 random bits per attempt; its acceptance probability is D/2^56 >1/2 and expected attempts <2. The first derivation's finite deterministic oracle/data caps do not depend on the number of selection attempts. Its byte/word time envelope excludes random-selection overhead unless the finite-distribution draw is primitive. With binary randomness, add O(56*r_sel) selection operations for the actual attempt count; the expected overhead is <112 bit draws, while a deterministic worst-case bound on exact rejection sampling is not claimed. No truncation to a fixed number of selection attempts is used, since that would add a failure term or bias the uniform address law.
