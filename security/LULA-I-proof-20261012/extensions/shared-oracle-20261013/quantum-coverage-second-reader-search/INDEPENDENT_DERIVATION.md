# Independent quantum coverage/base-inner search derivations

Saved before reading root `QUANTUM-COVERAGE-DRAFT.md`. This is a query-complexity argument conditional on an already justified source-to-programmed-ghost projection, not its proof or a complete QROM bound.

## 1. Source and primary anchors

The pinned source `release/code/lula1/src/lib.rs` SHA-256 is `ac8e67f05af68dd8e1291c5909847f74103903fb7ffa2c70f500c6ec48f14210`. Direct source reads at164–187 give

```
I(R,m)=R16||S16||root16||m,
E(U,c)=U32||BE32(c)||S16.
```

The full inner image U and full outer image D have256bits. The second function hashes exactly52bytes. It is not an oracle only for truncated outputs.

Hülsing–Kudinov, [ePrint2022/346](https://eprint.iacr.org/2022/346), Definition9/Theorem4, physicalpage23 of the cached primary PDF SHA-256 `80dcd11e56448d07e2a2465a11ef1a9ca8f4561387abeb3fabdd6d40d4ffe3c3`, gives `Succ <= 8 lambda (Q_B+1)^2` for outputting a marked point in an iid Bernoulli Boolean oracle. The page was checked directly with pypdf again in this task. This is a search-output theorem, not a statement about touching a point in a superposition.

## 2. Required programmed-ghost premise

Assume q exogenous fresh-message row templates with independently preminted first-accepted exposure vectors Xi=(bucket,17 real indices). They, their rejection noise/full-image suffixes, and exogenous full256 namespace labels Ui are independent of the static full256 BASE table. Actual completed exposures form a subset of these q slots; repeats add no independent exposure and failed calls supply no completed output. Padding remains by the deterministic signing-attempt cap q, not an expected count. A failure slot may have an unused independent latent Xi only if that exact padding/template construction has already been justified.

The server maintains a current mapping Gamma from signed message/inner strings to assigned Ui and from assigned outer prefixes to their row templates. Gamma changes according to adaptive classical signing requests. Its labels can depend on earlier BASE answers through the adversary's message choices. **Gamma is algorithm state, not independent auxiliary advice.** The reduction samples independent primitive data, then runs that same server and adversary to construct Gamma online. It must not condition on the final Gamma/query log and assert BASE remains independent.

Fresh Ui values must really be exogenous, independently sampled values in this ghost. Deriving a target list by inspecting BASE and retaining preferred outputs would invalidate the inner-search density. Rejection of labels based on BASE or hidden query flags needs the source bridge's own argument/loss. Giving row templates early is an information extension; giving adaptively collected BASE values or final message-label assignments as supposedly independent functions is not.

Use the disjoint raw languages

```
L_I = strings of length>=48 with bytes16..31=S;
L_C = strings of length52 endingS, with bytes16..31 != S.
```

The latter represents E(U,c) with U_low!=S. Other source hash interfaces are outside L_C; on nonzero S, addressed hashes are outside L_I. For the fresh final inner point to be an unpatched BASE lookup, current assigned Ui must also satisfy Ui_low!=S, or the corresponding namespace-alias event must already be charged. Nonzero S alone does not exclude an I/E alias. This guard is a required projection qualification.

## 3. Outer coverage marking and exact full-image factorization

Let Tq be the coverage sets generated by all q latent Xi. For each bucket b and real tree j, Tq(b,j) contains the indices disclosed in that slot dataset. Define P_T(D) to require the omitted9-bit digit to be zero and every real index of D to lie in Tq at D's bucket. Let

```
lambda_T = p(Tq) = Pr_uniform256D[P_T(D)].
```

Condition on the **independently sampled template data**, including Tq, not the adaptive transcript. Sample an iid Boolean B over all words of a finite injective raw-input register with density lambda_T. At each x in L_C independently sample full256 values V1(x) uniformly from P_T and V0(x) uniformly from its complement. Set BASE(x)=V_B(x)(x). The mixture is exactly uniform256 and independent across raw points. Every word outside L_C has an ordinary full256 outside-function value sampled independently of B; irrelevant Boolean marks are ignored. For lambda_T=0/1 use the degenerate case rather than divide by an empty set.

For a currently patched raw x, the public response is the fixed template/inner-patch image from Gamma instead of BASE(x). In the simulation set both response choices to that patch image at such x, using Gamma's current state. Otherwise use the original independent pair tables. A single Boolean XOR query implements the response by the clean pivot-transform/plus-work swap; on patched/outside branches the equal-choice response has zero delta and the query on |+> is harmless. Gamma may depend on preceding B responses: adaptive algorithm state is allowed by the search theorem. It is not allowed to hard-code that challenge-dependent final state as independent advice.

Future Ui namespaces that have not been assigned are still BASE in this experiment. Their BASE counter rows cannot be granted as independent outside tables if they belong to L_C. The independent *template* rows are different objects and are installed only according to the server's current patch rule.

## 4. Observable final C witness and averaging

The adversary makes Q raw complete-hash queries. Each is simulated with at most one B query, coherently across the input languages/current patch mask. Honest server metadata/patch assignment uses only the independent templates, private maps and outside tables under the assumed projection; if it performs additional unpatched BASE_C calls, those need to be counted rather than declared free.

After classical output, compute the final I point using the independent outside L_I function and current inner patch rule. For a fresh message it is not a prior signed-message inner patch, by fixed-width I framing. The final C point is E(U*,c*). On U*_low!=S and U* outside currently assigned prefixes, it is an unpatched point of L_C. Querying its full image uses at most one additional B call. If its digest is covered by the actual exposed sets, it is covered by Tq and this raw point has B(x)=1. Output x as a classical search witness. No quantum-history extraction or measurement is needed.

The conservative count is Q_B<=Q+1, hence

```
Pr(E_C | template data) <= min(1,8*(Q+2)^2*p(Tq)),
Pr(E_C) <= min(1,8*(Q+2)^2*E[p(Tq)]).
```

The latter follows by averaging the conditional theorem; averaging a capped bound can only lower the uncapped linear expectation. No conditioning on adaptive message assignments is performed. Omitting the final probe can sometimes sharpen the count when only an output predicate is needed, but is unnecessary for the stated conservative inequality.

For iid Xi with B0=2^41 buckets, t=512 real-index choices and17 real trees,

```
E[p(Tq)] = (1/t)*E[(1-(1-1/t)^K)^17],
K ~ Bin(q,1/B0).
```

The factor1/t is the omitted digit condition; the unused53 digest bits remain full uniform oracle information. This occupancy calculation belongs to the exogenous template premise. It cannot be used to prove that premise for the original deterministic signer.

## 5. Separate full256 inner-image bad search

Fix independently sampled S and the entire q-element exogenous Ui list. Define

```
D_bad = {U: U_low=S} union {Ui: i<=q}.
```

For uniform full256 U, with N=2^128,

```
lambda_I = |D_bad|/N^2 <= 1/N + q/N^2.
```

Duplicate Ui or overlap with the low-half set reduce the exact density. It is safe to use all q labels, even if the actual old assigned list is only a subset. Given this independent data, factor BASE on L_I into uniform values inside/outside D_bad using independent Bernoulli density lambda_I; outside L_I is an independent function table. Full256 outputs are preserved.

Run the adaptive patch/server assignment as algorithm state exactly as above. Known inner patches return an assigned Ui and ignore the Boolean mark. Fresh final m cannot have the same I string as a previously signed message, even if a transmitted R repeats. Guarded assigned outer prefixes cannot alias L_I. Thus final I is an unpatched BASE_I point. Q raw queries plus one conservative final I probe give

```
Pr(E_I) <= min(1,8*(Q+2)^2*(1/N+q/N^2)).
```

If the final I was queried earlier, this is still an output-search event, not a new independent-draw claim. If it was unqueried, the theorem's +1 naturally handles that possibility. Freshness eliminates only identical signed-message inputs, not arbitrary chosen R values. All pre-key queries use the same completed BASE table from time zero.

## 6. Common probability bookkeeping and exact boundaries

In a ghost where the final I is an unpatched BASE point and all currently assigned Ui satisfy the namespace guard, a final accepted covered-leaf route either has E_I or has a fresh guarded C point whose raw digest satisfies E_C. Therefore

```
Pr(covered final route)
 <= Pr(E_I)+Pr(E_C)
 <= min(1,8*(Q+2)^2*(1/N+q/N^2+E[p(Tq)])).
```

This adds event bounds in the **same programmed ghost**. Independent search reductions may use separate Boolean factorizations as proof devices because each preserves that ghost's ordinary full-function marginal. They do not create two independent real execution oracles or justify mixing different conditional projections.

The source-to-ghost distance, zero seed, bad assigned-label lower halves/collisions, finite counter failure, secret-map replacement and other forgery branches remain separate. Any such conditioning must be paid by its projection or retained as an explicit event. In particular, a current Ui with Ui_low=S can make a final I point alias a patched E point; the quoted uniform-BASE_I density then does not apply. Random-root assumptions cannot be invented to repair this omission.

All tables/row data may be huge. These are information-theoretic query reductions, not PPT simulations. No efficient challenge embedding, source/QROM capacity or full-security conclusion is derived. Exact controls and a root stage4/stage5 review will follow only after this first argument is saved.
