## 3. Injective variable-length encoding and invalid registers

**PROVED — domain.** Let X_b be all byte strings of length0,...,b. V_b=sum_(ell=0)^b256^ell. A length-sensitive lexical rank is
E(x)=sum_(j<ell)256^j+integer_big_endian(x), ell=length(x).
It is a bijection X_b to0,...,V_b-1, preserving leading-zero and empty-string distinctions. For b>=1, V_b<2^(8b+1). Fixed source b can be max(598,48+maximum-message-length,maximum-adversarial-raw-input-length).

**PROVED — quantum extension.** Specify a fixed query register containing a length field plus b padded bytes. Canonical valid encodings have ell<=b and all unused trailing bytes zero. The source/function extension acts as XOR0 on every invalid/noncanonical register state. Reversibly test validity, computeE only on valid data (default0 otherwise), evaluate the family into scratch, copy its256-bit output into the response only on the valid/outside branch, then uncompute. Selected-header routing additionally checks valid encoding and the actual86-byte header, and supplies canonical payload registers to Selected. Invalid source states never obtain a fresh random polynomial value. Inactive plus-response routing retains the accepted oracle access convention. If another baseline query-register extension is chosen, it must be matched explicitly; the theorem here fixes this zero extension rather than silently changing malformed states.

**PROVED — encoding cost.** Public offsets for0..b occupy O(b^2) bits and can be generated by exact shifts/additions. Reversible bounded comparisons, trailing-zero tests and offset selection/addition admit a conservative O(b^2) gate/space envelope. The field input is the m-bit binary representation ofE(x), interpreted in the tower basis below. Distinct integers are distinct field elements; no modular reduction/length alias is applied.

## 4. Deterministic field construction in tower coordinates

**PROVED — no modulus search.** Choose k=min(max(1,2T),V_b). Choose field degree m as the smallest power of two with m>=max(256,8b+1,ceil(log2 k)). Then m<=2 max(256,8b+1,ceil(log2 k)) and k<=V_b<=2^m. Use a direct binary tower representation, not conversion to one monogenic binary polynomial basis. No irreducible-polynomial search, random trial, assumed free exponential preprocessing or unspecified Las Vegas tail is needed.

**PROVED — construction and irreducibility.** Start F_1=GF(2), alpha_1=1 with absolute trace1. Suppose F_m has degree m and element alpha_m of trace1. Adjoin t with t^2+t+alpha_m=0, representing a+b t by two m-bit components. The mapz->z^2+z has image equal to the trace-zero subspace: its kernel is{0,1}, its image has2^(m-1) elements and lies in tracezero; the existing trace-one alpha_m ensures that subspace has the same size. Therefore alpha_m is not in that image, the quadratic has no root and is irreducible. Its extension has degree2m. The nontrivial relative conjugation sends t to t+1, so Tr_(F_2m/F_m)(a+b t)=b. Taking alpha_2m=alpha_m*t gives absolute trace1. In the recursive coefficient basis this alpha is always the highest single basis bit, value1<<(m-1) at degree m. The whole field descriptor is determined by degree/levels and those public highest-bit constants, O(m) descriptor bits/writes; this is an inductive field proof, not a kernel-certified tower.

**PROVED — addition/multiplication circuit.** Addition is bitwise XOR. At degree2m, for a+b t and c+d t compute
A=ac, B=bd, C=(a+b)(c+d), D=B alpha_m,
low=A+D, high=C+A.
This equals ac+bd alpha_m+(ad+bc+bd)t. There are four lower-field multiplications and O(m) XORs. Classical straight-line Boolean multiplication circuits satisfy M(2m)<=4M(m)+O(m), M(1)=O(1), hence O(m^2) gates/intermediate bits. Compile that entire circuit reversibly, XOR its result into a separate output register and uncompute scratch; this incurs only a constant-factor gate increase and O(m^2) ancillas. It does not repeatedly double recursion at every call. General field multiplication is therefore deterministic polynomial cost in m. Highest-bit multiplication uses this same upper bound; no fast unstated circuit is required.

## 5. k-wise family and exact whole-B law

## 6. Initialization, coherent Eval and total resource charges

**PROVED — coefficient initialization.** Sample km independent random bits, write/store km coefficient bits, construct the deterministic tower descriptor O(m), and construct the O(b^2) public lexical-offset/validation descriptor. k and m are static circuit parameters fixed before interaction. Initialization is O(km+b^2) bit writes plus deterministic polynomial descriptor/index computations, not32V_b bytes of table startup. Each sampled coefficient is a uniform m-bit field coordinate, so no rejection sampler is used.

**PROVED — reversible Horner Eval.** Compute Horner accumulators using multiplication/addition, keeping the previous m-bit accumulator rather than irreversibly overwriting it (x=0 would otherwise lose information). k accumulators use O(km) scratch; one multiplication circuit uses O(m^2) additional cleaned ancillas. Copy the projected256 bits into the response and reverse all Horner work. Gate count is O(km^2+b^2), workspace O(km+m^2+b^2), besides coefficient storage and input/response registers. Source classical lookups evaluate the SAME fixed polynomial coefficients at the same encoding; they do not sample a second lazy raw function. One Selected and one local Eval routing per logical raw query retains the earlier Q query resources.

**PROVED — whole cost and qualification.** At mostT outside Eval operations cost O(T*(km^2+b^2)) gates, with k<=max(1,2T), m=O(b+256+logT). Add t_A, source bookkeeping/private F/J table work, the unchanged challenge selected-query costs and type7 at-most2^32 canonical preprocessing. This is polynomial in COMPLETE source/reductionT and maximum byte length b. It is not practical for those enormous fixed worst-case source budgets, not a measured wall-clock result and not an efficient polynomial-in-treeheight assertion. It removes the previous exponential-in-byte-domain eager-table resource obligation for these bounded reduction outputs, while preserving every static time/query ledger.
