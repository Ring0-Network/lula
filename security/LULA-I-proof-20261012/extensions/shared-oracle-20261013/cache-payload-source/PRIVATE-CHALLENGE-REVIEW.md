## Exact interface issue

B_P inherits that same program. Both must instead start A in its pre-key phase, give only the Raw interface, withhold S/pk and signing, preserve A's state across its explicit setup transition, and only then run/return the keygen response. If the game permits the pre-key phase to be optional, the immediate-setup transition is its zero-query special case. This is an interface repair, not a new cryptographic argument or a new resource term.

## Partiality and implementation-envelope interpretation

**PROVED — accepted mathematical totalization.** Every grind tests at most 2^32 distinct counters; if all fail, the modeled service is absorbing/nonwinning. A release wrap revisits the same deterministic cycle and never completes, while a debug overflow can panic. The totalized reduction returns 0 for such a no-response branch, matching its winning indicator without claiming literal Rust equivalence of abort APIs or total runtime. Successful maximal counter 2^32−1 returns before overflow. Setup and signing prefix counts obey the same caps.

**PROVED — conservative relative resource envelope.** A single-thread source adapter can serialize independent deterministic keygen jobs. Each addressed fixed input has at most 598 bytes, each output node/full oracle word has constant size, and each chain/hash/tree/acceptance operation has bounded overhead. Address/message dictionaries add balanced-tree comparisons; the stated `C` may be one universal constant for this fixed parameter set and word-RAM encoding. Byte-length-dependent work belongs to M and L_A, and oracle evaluation is explicitly excluded. The bound is finite source-relative cost, not a measured time or a cryptographically parameter-uniform PPT theorem. Optional public-call memoization needs its own key-comparison cost if enabled; the given nonmemoizing adapter does not require that optional feature. Space allowances cover private full256 tables, message state, 5,720-byte transcripts, top cache and temporary vectors. Neither entire secret forest nor infinite raw RO table is materialized by the adapter.
