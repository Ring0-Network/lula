# Exact miss sampling and efficiency boundary

This clarifies independent-first1cf6aca9 without modifying it. The miss-prefix sampler is EXACTLY uniform over the N-1 values different fromY. A rank in{0,...,N-2} mapped by skippingY implements that finite distribution mathematically. Truncating or taking a biased modulo reduction from n fair bits does not implement it. Hit prefixes equalY; lower limbs are independent uniform. Their weights1/N and1-1/N then give the exact uniform full-word law.

For the information-theoretic query proof one may condition on the entire independent hit/miss/outside tables, X,Y,P and known designated lower limb. Every such fixed side-data realization specifies a finite known circuit; the average-search bound is uniform over the algorithm and therefore also holds after averaging these independent tables. The circuit may be enormous. In a selected row of N inputs, the miss prefix table alone has entropy N*log2(N-1) bits and can be encoded using N*n bits; independent lower limbs, hit tails, outside tables and metadata add their own storage. Known-function compilation/evaluation, exact sampler randomness and all local gates/time/space must be charged separately from the Q Boolean calls. No actual full table is generated by this work.

The prior binary polynomial bounded-independence simulator is NOT imported for the non-power-of-two miss alphabet. An efficient version would need a distribution-exact bounded-query replacement for that N-1-valued table, joint with its conditional hit/miss completion and outside oracle, plus charged uniform reversible evaluation. That is a separate smallest efficiency lemma, not needed for this finite query-only inequality. It must not be replaced by an unsupported claim that binary projection automatically has the required distribution.
