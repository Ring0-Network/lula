**PROVED / COMPUTED (one-cell negative control).** A retained genuine earlier link can bias the next query to the supposedly uniform cut input. If U0=1, W is an independent residual prefix and equals U1 with probability1/2. Therefore cut query mass is3/4>1/N. The cut input still has a uniform marginal.
